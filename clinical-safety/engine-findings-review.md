# Engine findings from the web and desktop form build

The review distinguished scoring defects from unsupported interpretations, input errors, missing audit detail and UI-only enhancements. Guardrails described below are entry checks, not claims about validation populations. All examples and tests use synthetic inputs.

| Finding | Disposition and evidence |
| --- | --- |
| Charlson age adjustment and field wording | Ages 50–59 score 1, 60–69 score 2, and so on. A regression test covers decade boundaries and the worked example of age 60 with a comorbidity score of 3 yielding 5 ([Charlson 1994, p. 1246](https://www.publichealth.it/wp-content/uploads/2020/05/3.-Validation-of-a-combined-comorbidity-index.pdf)). `working` records whether adjustment was selected. Removed the conflicting renal-stage and HIV wording; the existing asserted predicates remain. |
| CHALICE | Under 16 only; reject contradictory GCS flags. The form limits age to 0–15 completed years. The test covers the upper boundary and both age branches ([Dunning et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC2082967/)). |
| Bishop | Keep favourable cervix at ≥8 and the NICE induction-method cutoff at >6 separate. Scores 6, 7 and 8 are tested and component points are returned ([NICE NG207](https://www.nice.org.uk/guidance/ng207/chapter/recommendations)). |
| Familial hypercholesterolaemia | DLCN takes the highest-scoring criterion per group. Personal and family tendon xanthomata are distinguished. If a legacy request asserts xanthomata without saying whether the patient has them, the engine rejects it instead of awarding six points by assumption. Simon Broome can classify on qualifying DNA evidence alone. The shared form asks about confirmed causative DNA once; both wire fields remain available. The existing `above8_5` slug still includes 8.5 mmol/L, as in [ESC/EAS Table 12](https://doi.org/10.1093/eurheartj/ehz455), rather than the printed `>8.5` in [Nordestgaard Table 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC3844152/table/EHT273TB1/). [NICE CG71 Appendix F](https://www.nice.org.uk/guidance/cg71/evidence/full-guideline-appendix-f-pdf-241917811) provides the Simon Broome definitions. |
| FENa and FEUrea | Forms require the reported unit for each creatinine value, and for each urea or urea nitrogen value in FEUrea. The engine converts explicitly declared pairs; a partial declaration fails. The old four-number contract still means each pair is already in matching units. Results above 100% keep the numeric estimate but withhold clinical classification and prompt a unit/sample check; this is not a physiological claim that FEUrea cannot exceed 100%. No check can infer units or catch all errors in legacy requests (H002). |
| QFracture | Engine and form reject inputs outside 50–250 cm or 20–500 kg, matching the broad adult BMI entry checks in this library. These are not [QFracture-2012](https://www.bmj.com/content/344/bmj.e3427.full) derivation limits; the model and coefficients are unchanged. |
| EuroSCORE II and ASCVD | Removed uncited EuroSCORE II labels; retained its predicted mortality. ASCVD keeps the 2013 Pooled Cohort Equations and names the [2018 AHA/ACC guideline](https://doi.org/10.1161/CIR.0000000000000625) as the source of its interpretive bands. |
| HAS-BLED | `elderly_over_65` remains an explicit predicate with a strict `>65` definition. It is a supported input shape, not a scoring defect; the calculator does not require a date of birth or infer the assertion. |
| MAP, Lund–Browder and QTc | Consistent rounding across response fields and prose. MAP compares the unrounded value and shows extra digits when one decimal would round a below-target value to 65.0 mmHg. Lund–Browder names Parkland's actual `burn_tbsa_percent` field. QTc tests the Hodges half-millisecond case. |
| PSI/PORT, shock index, maximum heart rate, Canadian C-spine, Binet and protein target | Corrected sentence case, nested parentheses, wire-field names and raw booleans in interpretation. Wells DVT documentation now describes only its implemented NICE two-level interpretation. |
| Numeric validation | PESI, serum osmolality and shock index enforce the ranges already advertised by their schemas. GRACE 1.0 accepts adults with positive measured heart rate and systolic BP; arrest remains its separate predictor. The Duke-ISCVID temperature check rejects likely Fahrenheit entry, preserves 46 °C and leaves the fever criterion strictly >38 °C. APACHE II's schema describes the variables, oxygenation branches and chronic-health eligibility and reflects explicit measurement guardrails. Corrected calcium rejects a common mg/dL-as-mmol/L error and advertises albumin ranges. |
| Unit discovery | A/G ratio, BUN/creatinine, HbA1c/eAG and transferrin saturation advertise the same per-unit ranges the engine applies. Corrected sodium documents its exact mg/dL conversion and the accepted range at two decimal places. Winters' formula and A–a gradient accept explicitly named kPa alternatives, without changing the mmHg output. Calvert AUC and GFR have unit metadata. |
| Gestational age | A regular cycle-length adjustment now shifts both gestational dating and estimated due date, so the adjusted due date is at 40 weeks. The schema distinguishes the [cycle-length correction](https://www.merckmanuals.com/professional/pediatrics/perinatal-problems/gestational-age) from [ACOG's clinical dating guidance](https://www.acog.org/clinical/guidance/committee-opinion/2017/05/methods-for-estimating-the-due-date/). A reference before the adjusted start is rejected; prose uses singular days and weeks correctly. |
| AUDIT and EPDS | AUDIT uses the [WHO 2001 Box 10 self-report form](https://iris.who.int/server/api/core/bitstreams/c57d9855-5450-4c46-84b1-c88a6df4192c/content), not a mixture of interview and self-report versions. The schema includes the score keys and disallows 1 or 3 for items 9 and 10. EPDS has conflicting reproduction notices; [CamCOPS records that the Royal College did not permit software embedding](https://camcops.readthedocs.io/en/stable/tasks/epds.html#intellectual-property-rights). Keep scoring and the item 10 flag, but use an authorised external form and do not redistribute item or answer wording. |
| Structured working | Added Ottawa Knee's decision, daily Holliday–Segar volume, ideal weight, HbA1c/eAG in mmol/L, component points for FINDRISC, APACHE II and Braden, heparin bolus and adjustment fields, and bands for Barthel, anion gap and waist-to-height ratio. Barthel no longer parses prose. BASDAI schema specifies the response anchors. Removed the unreachable 4AT branch without changing scoring. |
| Body composition | Removed category labels not evidenced by the Navy circumference equations. The estimate must be within 0–100%; no arbitrary measurement ceilings were added. WHR uses a readable display without rounding up across its cut-off and preserves numeric precision. RFM already formats prose at one decimal; its raw numeric output is intentional. `Male`/`Female` remain the existing ideal-body-weight wire values. |
| Proposed caps | No therapeutic fluid cap was added to Holliday–Segar, and no new cut-offs were invented for Khorana or ISTH overt DIC. These formulas and scores use open-ended upper bands; local treatment limits are separate. |
| GUI-only findings | Horizontal choices, boolean/object response types and the IPSS typecheck were resolved in the form deployment. The generic smoke inputs for ARDSnet, Jackson–Pollock and US Navy body fat intentionally fail their cross-field checks. The exclusive-minimum field improvement is [ENG-016.1](../spec/roadmap.md#eng-016-form-number-bounds). |

## Compatibility

The affected calculators keep their names. Older JSON requests remain valid unless the inputs are now rejected for scope, plausibility or ambiguity. Typed Rust callers constructing `FenaInput`, `FeureaInput` or `FamilialHypercholesterolaemiaInput` with struct literals must initialise the added optional fields. New `working` fields are additive; both the FENa/FEUrea string results and the blood-gas mmHg result units are retained.

## Reproduce the checks

Run `s/test` for the Rust gate across feature sets. Build the evaluation playground with `s/web-build` and run `python3 gui/tests/engine-form-regressions.py gui/dist-web` with Python Playwright and Chromium installed. The browser cases exercise the mixed-unit requests, MAP display at the threshold, a kPa blood gas, and the EPDS position-to-score and self-harm path.
